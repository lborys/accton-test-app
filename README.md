# 🌳 Vue Category Tree Component

Простий застосунок для відображення/вибору/видалення дерева категорій.

## ⚙️ Технології

- Vite — швидкий збирач проєктів  
- Vue 3 — прогресивний фреймворк для інтерфейсів  
- TypeScript — типізований JavaScript  

## 🚀 Швидкий старт

Клонуй репозиторій і зайди в папку:

git clone https://github.com/lborys/accton-test-task.git
cd accton-test-task

1. Встановити залежності: npm install

2. Запустити локальний сервер розробки: npm run dev

3. Зробити білд для продакшену: npm run build

## Опис

Цей компонент відображає дерево категорій з можливістю пошуку та мультивибору. Підтримує:

- Пошук з фільтрацією: при введенні в рядок пошуку відображаються лише ті категорії, які співпадають із запитом, а також їхні батьківські вузли для контексту.  
- Мультивибір категорій з рекурсивним вибором дочірніх категорій: якщо вибрати категорію з дочірніми елементами, вибираються і вони.  
- Підтримка кастомізації вузла через slots, з доступом до всіх даних вузла.  
- Відображення вибраних категорій у вигляді тегів з можливістю видалення.

## Режими роботи

- **Режим за замовчуванням** — порожній пошуковий рядок, відображається все дерево.  
- **Режим пошуку** — вводиш текст, дерево фільтрується за запитом, показуються знайдені категорії та їхні батьки.  
- **Відображення вибраних** — рядок з тегами обраних категорій, кожен тег можна видалити, щоб прибрати вибір.
